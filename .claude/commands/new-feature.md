Triển khai tính năng được yêu cầu: $ARGUMENTS

Thực hiện theo skill `frontend-feature`. Trước tiên, kiểm tra hướng dẫn repository, `code-map.md` và `git status`, sau đó truy vết route/view liên quan, UI có thể tái sử dụng, endpoint BE (`../BE/Ai_rules/code-map.md`) và style. Trình bày kế hoạch ngắn gọn trước khi sửa nếu phạm vi đi qua nhiều module hoặc ảnh hưởng hành vi. Giới hạn diff trong yêu cầu, triển khai tính năng, chạy bước kiểm tra phù hợp và báo cáo file, kết quả xác minh cùng điều chưa rõ. Không tự đặt hành vi API hoặc dùng dữ liệu giả làm phương án dự phòng.
